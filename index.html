Connection and storage log

Compact live observations and imported outcomes are saved on this device using browser local storage. High-frequency ticks are kept in memory for approximately 65 seconds; compact observations are stored locally. The history is limited by browser storage and may disappear if you clear site data or open the file under a different address. Monitoring stops when the browser is closed; Android may throttle background tabs. This is not a 24/7 server.

Important limitations

This version does not connect to the official CF Benchmarks BRTI live or historical feed, and it cannot reconstruct exact final-minute settlement averages. Historical Kalshi order-book prices, spreads, fills, and verified settlements are not automatically backfilled. The colored history arrows are Coinbase-only estimates. The third-party Kalshi feed and Coinbase HTTP endpoints may not permit cross-origin requests from a local HTML file; WebSocket access may also be restricted. If they fail, the dashboard reports errors. No orders are placed.

Version 3.5 notes

Historical data uses Coinbase BTC/USD one-minute closing prices, with OHLC values retained for export. Fifteen-minute statistics compare closing prices 15 minutes apart; they do not reconstruct the intra-minute path or Kalshi settlement.

Coinbase Exchange BTC/USD trade ticks are streamed over a public WebSocket when available, with one-second HTTP spot polling as a fallback. WebSocket trade messages can be delayed or missed; browser suspension and network disconnections remain possible. The Kalshi third-party feed is requested roughly every ten seconds and may fail. The CF Benchmarks settlement index and historical Kalshi order books are not connected. This is research-only, not a trading signal.

Observations are saved locally in this browser (subject to storage limits); export regularly. Browser file security restrictions may prevent public API requests.
